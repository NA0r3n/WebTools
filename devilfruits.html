Paramecia

Paramecia-type Devil Fruits grant a wide variety of supernatural abilities that do not fall under the Zoan or Logia categories.

Ope Ope no Mi

User: Trafalgar D. Water Law
Type: Paramecia
Ability: Creates a spherical "ROOM" in which the user can manipulate objects, bodies, and other targets.

Gura Gura no Mi

Users: Edward Newgate / Marshall D. Teach
Type: Paramecia
Ability: Creates powerful vibrations capable of producing devastating earthquakes and shockwaves.

Bara Bara no Mi

User: Buggy
Type: Paramecia
Ability: Allows the user to separate their body into pieces while maintaining control over them.

Hana Hana no Mi

User: Nico Robin
Type: Paramecia
Ability: Allows the user to sprout copies of their body parts from nearby surfaces and objects.

Yomi Yomi no Mi

User: Brook
Type: Paramecia
Ability: Allows the user's soul to return after death and grants various soul-related abilities.

Suke Suke no Mi

User: Shiryu
Type: Paramecia
Ability: Allows the user to become invisible, including anything they touch.


Zoan

Zoan-type Devil Fruits allow their users to transform into animals or animal-human hybrid forms.

Normal Zoan

Hito Hito no Mi

User: Tony Tony Chopper
Type: Zoan
Ability: Allows the user to transform into a human and various hybrid forms.

Ushi Ushi no Mi, Model: Giraffe

User: Kaku
Type: Zoan
Ability: Allows the user to transform into a giraffe and a giraffe-human hybrid.

Mythical Zoan

Hito Hito no Mi, Model: Nika

User: Monkey D. Luffy
Type: Mythical Zoan
Former Name: Gomu Gomu no Mi
Ability: Grants the user the properties of the legendary Sun God Nika and allows extraordinary freedom in combat.

Tori Tori no Mi, Model: Phoenix

User: Marco
Type: Mythical Zoan
Ability: Allows the user to transform into a phoenix and regenerate using special blue flames.

Uo Uo no Mi, Model: Seiryu

User: Kaidou
Type: Mythical Zoan
Ability: Allows the user to transform into an Azure Dragon and a hybrid form.

Inu Inu no Mi, Model: Okuchi no Makami

User: Yamato
Type: Mythical Zoan
Ability: Allows the user to transform into the divine wolf known as the Okuchi no Makami and a hybrid form.


Logia

Logia-type Devil Fruits allow their users to create, control, and transform into a natural element or force of nature.

Mera Mera no Mi

Users: Portgas D. Ace / Sabo
Type: Logia
Ability: Allows the user to create, control, and transform into fire.

Goro Goro no Mi

User: Enel
Type: Logia
Ability: Allows the user to create, control, and transform into lightning.

Hie Hie no Mi

User: Kuzan
Type: Logia
Ability: Allows the user to create, control, and transform into ice.

Magu Magu no Mi

User: Sakazuki
Type: Logia
Ability: Allows the user to create, control, and transform into magma.

Pika Pika no Mi

User: Borsalino
Type: Logia
Ability: Allows the user to create, control, and transform into light.

Suna Suna no Mi

User: Crocodile
Type: Logia
Ability: Allows the user to create, control, and transform into sand.

Moku Moku no Mi

User: Smoker
Type: Logia
Ability: Allows the user to create, control, and transform into smoke.

Yami Yami no Mi

User: Marshall D. Teach
Type: Logia
Ability: Allows the user to create and control darkness and its gravitational properties.



These are only a few of the many Devil Fruits that exist in the world of One Piece.
